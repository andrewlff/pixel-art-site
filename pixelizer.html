Free & Open Source

Free & open-source pixel art + animation frame tool. Runs in your browser, no install needed.

Three Ways to Use

Single Image — Quickly convert any image to pixel art
Animation Frames — Import PNG sequence or video, auto-extract frames, remove BG, export Sprite Sheet/GIF
AI Generate — Generate character action prompts for AI image tools
Import: PNG / JPG / WebP / MP4 / WebM · Export: PNG / GIF / Sprite Sheet / JSON
